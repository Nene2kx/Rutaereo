# RutaAero Fase 8

Nueva función:
- El conductor puede eliminar sus rutas.
- Aparece un botón 🗑️ Eliminar ruta en cada ruta.
- Pide confirmación antes de borrar.
- Al eliminar una ruta, también se eliminan sus puntos de recogida.
- Si la ruta tiene reservas, el sistema bloquea la eliminación para evitar perder reservas.

## Ejecutar
Detén la versión anterior con CTRL+C.
Descomprime esta versión.
Dentro de la carpeta:
npm install
npm start

Abrir:
http://localhost:3000
